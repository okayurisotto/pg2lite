# pg2lite

A script for migrating PostgreSQL data to PGlite.

## Example

Before proceeding, save the file generated by `pg_dump` as `./dump.sql`.

```sh
podman compose up --detach
podman compose exec postgres ash -c 'cat /dump.sql | psql -U example-username example-database'
podman compose exec pglite apk add postgresql16
podman compose exec pglite bun run ./src/main.ts
```

cf. `compose.yaml`
